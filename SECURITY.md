# Security policy

Codex WebUI is intended for trusted, private access through localhost or a
private network such as Tailscale. Do not expose it directly to the public
internet.

Please report vulnerabilities privately through GitHub's security advisory
flow instead of opening a public issue. Include the affected version, a concise
reproduction, and the likely impact. Do not include real credentials, session
cookies, private source code, or user data.

Security fixes are prioritized, but this community project does not currently
publish a formal support window or response-time guarantee.
