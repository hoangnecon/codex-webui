# Contributing

Thanks for helping improve Codex WebUI.

1. Open an issue for substantial behavior or protocol changes.
2. Create a focused branch and keep unrelated cleanup out of the change.
3. Run `npm run check` and `npm test`.
4. Never commit `.env`, credentials, sessions, uploads, logs, or generated
   protocol files.
5. Open a pull request describing the user impact, implementation, and checks.

Security issues belong in a private GitHub security advisory, not a public
issue.
